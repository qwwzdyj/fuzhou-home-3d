# 福州新家 · 3D 互动分享

**直接打开：[在线模型](https://qwwzdyj.github.io/fuzhou-home-3d/)**

可旋转、平移、缩放；自由漫游和相机地图；6 组门可交互；25 件原有家具 / 设备及 2 张新增试摆桌可删除、撤销与恢复；支持保存方案 JSON、导出 GLB 和截图。

### 全屋空间尺寸与双桌试摆（2026-11-04）

8 个空间均可点击标签、尺寸卡片或顶部“定位空间”，自动定位并显示宽深标尺；支持俯视、两间卧室对照、关闭标尺。客厅 / 小厅约 3.20 × 2.84 m（含右侧通行区域），阳台约 3.20 × 1.08 m（净高未确认），小卧室约 2.24 × 2.08 m，阳台卧室约 3.20 × 2.65 m。全部为模型参考，不是最终现场实测；面积仅为模型矩形范围。标尺参与截图，但不写入 GLB 几何。

小卧室靠主卧隔墙，新增两张白色 **100 × 60 × 75 cm** 书桌并排（屋主确认规格），中间留 2 cm，两侧按当前模型各余约 11 cm。桌架为示意。可切换 100 / 120 / 140 cm 长度并实时查看超宽提示；两张 120 或 140 cm 在这面墙并排会超宽，不会偷偷缩小家具。默认保留原床并显示平面范围重叠提示，可点“移走原床（可撤销）”比较腾空方案。并非完整碰撞或坐人空间验证。

新增桌与原家具一样可选中、删除、撤销；双桌配置随 JSON 保存 / 载入。已开启且未删除的桌会包含在导出 GLB 中，关闭方案则不导出；超出房间边界时阻止导出。载入旧版（没有双桌配置的）JSON 会关闭新桌，避免改变旧方案；已有浏览器存档首次更新时保留原删除记录并加入默认双桌。

## 尺寸说明

屋主确认的门扇宽度（门轴至门扇外缘 / 开门半径）：入户 86 cm、主卧 80.5 cm、次卧 76.5 cm、厨房 72 cm、卫生间 62 cm。其他部分尺寸、洞口、门框仍为建模参考，需现场复核。不是施工图，也不表示实际地理朝向。交互不含碰撞检测。

## 分享范围

仅发布网页、交互源码与三维模型。不含原始视频、照片、测量关键帧、本机路径或 Blender 工程。此仓库和模型公开可访问；`robots.txt` 仅请求不被索引，不是访问限制。

访客的家具删除、门状态与双桌配置仅存储在其当前浏览器；不会修改共享模型或其他人的方案。相机位置可随 JSON 保存 / 载入。没有后端、账号、分析脚本或第三方 CDN 资源；静态文件由 GitHub Pages 提供。

## 本地构建

```sh
npm ci
npm test
npm run build
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/`。`model-data.js` 是经过元数据白名单处理的模型和必要布局数据；已编译的 `viewer.js` 可直接运行。GitHub Pages 从 `main` 分支根目录发布。

Three.js 的许可见 `THIRD_PARTY_LICENSES.txt`。模型及自有代码未授予额外再许可。
