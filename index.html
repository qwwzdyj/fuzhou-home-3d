    欢迎来看看这个家

    不用安装 Blender。可以自由转动模型、开关门，试着删掉家具，看一看腾出的空间。

    怎么操作

    1. 电脑：左键旋转，右键平移，滚轮缩放。
    2. 手机：单指旋转，双指缩放或平移；“放大模型”可收起侧栏。
    3. 点击门开关；在“看模型”中选择门并拖动滑块，可调整开合程度。
    4. 选择“自由漫游”，用 WASD 或画面箭头走动；“相机地图”可直接拖动相机位置。
    5. 顶部“定位空间”可看客厅、阳台等 8 个区域的参考尺寸；“看双桌”定位小卧室新增书桌。
    6. 双桌试摆保留原床并提示重叠，可用“移走原床（可撤销）”比较方案。
    7. 点击整件家具后删除，支持撤销与恢复。导出 JSON 可保存方案，也可导出当前 GLB 模型。

    只改变你的方案

    家具删除、门状态与双桌配置只保存在你当前使用的浏览器，不会修改屋主的模型，也不会影响其他访客。长期保存请下载方案 JSON。相机位置可随 JSON 保存及载入。

    关于这个版本

    公开版只包含网页和三维模型，不包含原始视频、照片或本机文件路径。模型为现状 MVP，部分尺寸暂定；门与相机运动不包含碰撞检测，朝向不是实际指南针方向。

    查看与调整你的家

    1. 双桌方案：默认两张 100 × 60 × 75 cm 桌沿小卧室主卧侧墙并排，中间留 2 cm；可切换长度试算。次卧原床沿用屋主删除基准；恢复原床后重叠时可点“移走原床（可撤销）”。双桌启用状态、长度和删除记录会随 JSON 保存；GLB 包含已启用且未删除的桌子。旧 JSON 不含双桌参数时，按原方案关闭新增桌子。
    2. 空间尺寸：点击房间标签或“定位空间”，查看客厅、阳台、卧室、厨卫及走道的宽深标尺；侧栏可看净高、矩形面积和适用的门扇宽。“两间卧室尺寸对照”可同时俯视，点击“空间尺寸”关闭标尺。标尺随模型旋转，也会出现在保存的截图里；它们不写入 GLB。房间尺寸为参考，非最终实测。
    3. 门的交互：点击门扇或门框开关；侧栏选择门、定位、滑块调角度。5 扇平开门＋1 组阳台推拉门，支持撤销、刷新恢复与 JSON 保存。门开合不含碰撞检测。
    4. 旋转 / 拖拽平移：切换画面上方工具。平移模式左键拖拽就能改变取景中心，滚轮缩放。
    5. 自由漫游：左键拖拽转头；WASD 移动相机，Q/E 升降，Shift 加速。右键拖动或 Shift + 左键拖动平移。触屏可用箭头按钮移动。
    6. 相机地图：点地图或拖动相机圆点，直接设置位置；拖动高度滑块调整视点。地图不是指南针。
    7. 删除家具：点击模型选中整件，再点“删除这件家具”，也可在侧栏列表操作。支持撤销、恢复全部，刷新保留当前删除记录。
    8. 保存：JSON 保存/载入家具、门、双桌和相机方案；GLB 导出当前门姿态及删除后的完整空间。不会修改共享模型或其他人的方案。浏览器缓存可能被清理，长期保存请下载方案。
    9. R 回全屋、T 俯视、Esc 取消选择、Delete 删除选中家具。室内导航不含墙体碰撞，穿墙后可从地图重新定位。
    10. 五扇门宽已按屋主确认值更新；门框、洞口与其他暂定尺寸仍待测。测距为模型几何值，不代表现场实测。
