怎么操作

  1. 电脑：左键旋转，右键平移，滚轮缩放。
  2. 手机：单指旋转，双指缩放或平移；“放大模型”可收起侧栏。
  3. 点击门开关；在“看模型”中选择门并拖动滑块，可调整开合程度。
  4. 选择“自由漫游”，用 WASD 或画面箭头走动；“相机地图”可直接拖动相机位置。
  5. 点击整件家具后删除，支持撤销与恢复。导出 JSON 可保存方案，也可导出当前 GLB 模型。

只改变你的方案

家具删除与门状态只保存在你当前使用的浏览器，不会修改屋主的模型，也不会影响其他访客。长期保存请下载方案 JSON。相机位置可随 JSON 保存及载入。

关于这个版本

公开版只包含网页和三维模型，不包含原始视频、照片或本机文件路径。模型为现状 MVP，部分尺寸暂定；门与相机运动不包含碰撞检测，朝向不是实际指南针方向。

查看与调整你的家

  1. 门的交互：点击门扇或门框开关；侧栏选择门、定位、滑块调角度。5 扇平开门＋1 组阳台推拉门，支持撤销、刷新恢复与 JSON 保存。门开合不含碰撞检测。
  2. 旋转 / 拖拽平移：切换画面上方工具。平移模式左键拖拽就能改变取景中心，滚轮缩放。
  3. 自由漫游：左键拖拽转头；WASD 移动相机，Q/E 升降，Shift 加速。右键拖动或 Shift + 左键拖动平移。触屏可用箭头按钮移动。
  4. 相机地图：点地图或拖动相机圆点，直接设置位置；拖动高度滑块调整视点。地图不是指南针。
  5. 删除家具：点击模型选中整件，再点“删除这件家具”，也可在侧栏列表操作。支持撤销、恢复全部，刷新保留当前删除记录。
  6. 保存：JSON 保存/载入家具、门和相机方案；GLB 导出当前门姿态及删除后的完整空间。不会修改共享模型或其他人的方案。浏览器缓存可能被清理，长期保存请下载方案。
  7. R 回全屋、T 俯视、Esc 取消选择、Delete 删除选中家具。室内导航不含墙体碰撞，穿墙后可从地图重新定位。
  8. 五扇门宽已按屋主确认值更新；门框、洞口与其他暂定尺寸仍待测。测距为模型几何值，不代表现场实测。
